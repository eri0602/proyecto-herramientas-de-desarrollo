# Guía de contribución — Resiste

## Ramas
- `main` está protegida: solo entra código que funciona.
- Una rama por feature: `feature/auth`, `feature/metas`, `feature/tipos-actividad`, `feature/sesiones`, `feature/dashboard`.
- Trabaja solo dentro de tu módulo. Si necesitas tocar el de la otra persona, avisa antes.

## Commits (Conventional Commits)
Usa siempre uno de estos prefijos:
- `feat:` nueva funcionalidad
- `fix:` corrección de bug
- `docs:` documentación
- `test:` pruebas
- `chore:` configuración, tareas internas
